# 프로젝트 스킬 (Cursor)

이 디렉터리의 스킬은 **이 리포지터리에서만** 적용되는 프로젝트 스킬입니다.

## 현재 스킬

| 스킬 | 설명 |
|------|------|
| **multi-asset-invest-dev** | 프로젝트 구조, 문서 위치(PRD·스펙), api/worker/web 명령어(uv, alembic, pytest, ruff, pnpm), 스펙·FR 일치 가이드 |

## 사용 방법

- Cursor가 이 리포를 열고 작업할 때, 채팅/에이전트에서 프로젝트 구조·명령어·스펙 참조가 필요하면 해당 스킬이 자동으로 고려됩니다.
- 스킬을 **직접 호출**하려면 채팅에 예: "multi-asset-invest 스킬 참고해서 api 실행 방법 알려줘" 처럼 맥락을 넣으면 됩니다.

## 스킬 추가

- 새 스킬은 `스킬이름/SKILL.md` 형태로 추가합니다.
- 스킬 작성 가이드: Cursor 내장 스킬 **create-skill** 참고.
